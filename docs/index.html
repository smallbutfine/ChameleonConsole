What It Is

ChameleonConsole is a mono channelstrip plugin that emulates the tone and feel of 17 classic console eras — from a Neve 1073 to an MCI JH Series. The DSP is written in FreePascal (ZDF state-variable EQ/HPF/LPF, 2× oversampling, transformer & tape emulation, final slew limiter). The format/GUI shell is CLAP (wrapped to VST3 with clap-wrapper).

Click the era label under the VU to switch console era. Drag any knob to change its parameter; the DAW value follows (host notified).

Features

17 Console Eras

Neve 1073, API 500, SSL 4000G, Neve ISA, Mackie VLZ, EMI REDD, UA Classic, Telefunken V72, Helios 69, Hybrid, RCA SR-780, Detroit, Studer 169, Polar Nordic, Harrison 32C, Trident A-Range, MCI JH.

Channelstrip DSP

Trim, Drive, HPF, LPF, 3-band EQ (freq/gain), Lux, Gloss, Tape, Volume. ZDF filters, 2× oversampling, transformer/tape, slew limiter.

Ballistic VU

Real attack/release inertia (in the DSP), calibrated via vu.ini (min/max dB, frames) next to the sprite.

Sprite GUI

Per-era background, per-function knob sprite strips (101 frames), VU sprite. Drag to turn; click the era label to switch.

Automatable

All 15 params automatable; GUI changes notify the host (request_callback).

Tunable

knobs.ini per era sets each knob's curve/taper — tune the desk like an old engineer.
