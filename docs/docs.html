All automatable. GUI changes notify the host via request_callback; incoming PARAM_VALUE events apply in process()/flush().

GUI & Artwork

Per-era assets in assets/<era>/: background.png (90×852), knobs/<function>.png (50×5050 vertical sprite strips, 101 frames), vu.png (90×7070, 101 frames). Loaded DLL-relative. Click the era label under the VU to switch era; drag a knob to change its param.

VU calibration — vu.ini

[vu]
min_db=-40
max_db=3
frames=101

The DSP provides a ballistic (attack/release) level in dB; the GUI maps it to a frame via this calibration. 0 VU ≈ -18 dBFS.

Knob tuning — knobs.ini

[trim]
curve=linear
[volume]
curve=log

Per-function taper/curve so you can tune the desk like an old engineer.

State & Build

clap.state saves the gain + window size. Build with ./build_all.bat (CLAP + Windows VST3 + Deploy). macOS/Linux VST3 are native clap-wrapper builds.
